SmartMandi – Farmer Profit Advisor

About the Project

SmartMandi helps farmers compare different agricultural markets and estimate their expected returns after transportation costs and crop spoilage.

Problem Statement

Agricultural Market Intelligence & Dispatch Optimization.

Key Features

- Compare prices across different markets.
- Estimate transportation costs.
- Consider crop spoilage.
- Recommend the market with the highest estimated net return.

Current Status

This is an initial prototype using illustrative sample data. Live market prices and price forecasting will be added in future development.

Technology Stack

- CSS
